# Contributing to Sahatak

Thank you for considering contributing to Sahatak! We welcome contributions from everyone.

## How to Contribute

1. Fork the repository
2. Create a new branch for your feature or bug fix
3. Make your changes
4. Test your changes thoroughly
5. Submit a pull request with a clear description of your changes

## Reporting Bugs

If you find a bug, please open an issue and include:
- A clear description of the problem
- Steps to reproduce the issue
- Expected vs actual behavior

## Suggesting Improvements

We welcome ideas for improvements and new features. Please open an issue to discuss your suggestion before starting work.

## Code Style

Please follow the existing code style and conventions used in the project.

## Documentation

Update relevant documentation when you add or change functionality.

## Questions?

Feel free to open an issue if you have any questions.
